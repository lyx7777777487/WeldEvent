标注平台 MCP Server 接入文档

版本 1.0  |  2026-06-16

1. 概述

标注平台通过 MCP (Model Context Protocol) 暴露核心能力，AI Agent 可以通过自然语言操控标注数据：查询数据集、创建作业、查看进度、触发 AI 标注等。

传输协议Streamable HTTP（每次调用独立 POST 请求，无需维护长连接）
服务地址http://172.16.11.11:8079/api/mcp
MCP 端点POST /（JSON-RPC 2.0）
认证方式JWT Token，通过 Cookie 或 Authorization header 传递

2. 认证

所有 MCP Tool 调用需要携带有效 JWT。鉴权在服务端 nginx 层统一处理，和浏览器用户共用同一套 RBAC 权限体系。

2.1 获取 Token

1
用平台账号登录，获取 JWT
curl -X POST http://172.16.11.11:8079/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "your-username", "password": "your-password"}'
2
从响应中取 token 字段
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "userId": "01ABC...",
    "username": "agent-bot",
    "expiresIn": 86400000
  }
}

2.2 Token 传递方式

两种方式任选其一：

方式Header说明
Authorization（推荐）Authorization: Bearer <token>API 标准风格，所有 MCP SDK 原生支持
Cookie（不推荐）Cookie: jwt_token=<token>浏览器风格，向后兼容，建议仅 Web 场景使用

2.3 Token 刷新

Token 过期后调用 refresh 接口获取新 token，无需重新登录：

curl -X POST http://172.16.11.11:8079/api/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"token": "expired-token-here"}'

3. 可用 Tools

3.1 list_datasets — 列出数据集

描述分页列出当前用户可见的数据集
参数pageNum (int, 可选, 默认 1)   pageSize (int, 可选, 默认 10)
返回数据集列表，含 id、name、description、modality、创建时间

3.2 get_dataset — 查看数据集详情

描述获取单个数据集的详细信息及包含的图片列表
参数datasetId (string, 必填) — 数据集 ID
返回数据集详情 + 图片文件列表（filename、storagePath）

3.3 create_job — 创建标注作业

描述在指定数据集下创建标注作业
参数 datasetId (string, 必填) — 数据集 ID
name (string, 必填) — 作业名称
labels (string, 可选) — 标签列表，逗号分隔，如 "cat,dog,bird"
annotationType (string, 可选) — 标注类型，默认 CLASSIFICATION
platform (string, 可选) — 标注平台，默认 LABEL_STUDIO
返回创建的作业 ID

3.4 list_jobs — 列出作业

描述列出某个数据集下的标注作业
参数datasetId (string, 必填)   pageNum (int, 可选)   pageSize (int, 可选)
返回作业列表，含名称、状态、进度（completedCount / totalCount）

3.5 get_job — 查看作业详情

描述获取单个作业的详细信息及完成进度
参数jobId (string, 必填) — 作业 ID
返回作业详情，含 name、labels、status、总任务数、已完成数

3.6 list_tasks — 列出子任务

描述列出某个作业下的标注子任务
参数jobId (string, 必填)   pageNum (int, 可选)   pageSize (int, 可选)
返回子任务列表，含标注员、状态、进度

3.7 create_task — 创建标注任务

描述为某个作业创建标注子任务
参数jobId (string, 必填) — 作业 ID
返回创建的任务 ID

3.8 trigger_ai — 触发 AI 标注

描述触发某个作业下所有子任务的 AI 自动标注
参数jobId (string, 必填) — 作业 ID
返回触发成功确认

3.9 assign_task — 分配标注员

描述将子任务分配给指定标注员
参数 taskId (string, 必填) — 任务 ID
assigneeId (string, 必填) — 标注员用户 ID
assigneeName (string, 必填) — 标注员用户名
返回分配成功确认

4. 多语言接入示例

4.1 TypeScript / JavaScript

import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

// 1. 先登录拿 token
const loginResp = await fetch("http://172.16.11.11:8079/api/auth/login", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ username: "agent-bot", password: "xxxxx" }),
}).then(r => r.json());
const token = loginResp.data.token;

// 2. 连接 MCP Server，带上 token
const client = new Client({ name: "deerflow", version: "1.0.0" });
const transport = new StreamableHTTPClientTransport(
  new URL("http://172.16.11.11:8079/api/mcp/"),
  {
    requestInit: {
      headers: { Authorization: `Bearer ${token}` },
    },
  },
);
await client.connect(transport);

// 3. 列出可用 Tools
console.log(await client.listTools());

// 4. 调用 Tool
const result = await client.callTool({
  name: "list_datasets",
  arguments: { pageSize: 5 },
});
console.log(result);

4.2 Python

import httpx
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

# 1. 登录拿 token
resp = httpx.post("http://172.16.11.11:8079/api/auth/login", json={
    "username": "agent-bot",
    "password": "xxxxx",
})
token = resp.json()["data"]["token"]

# 2. 连接 MCP Server
async with streamablehttp_client(
    "http://172.16.11.11:8079/api/mcp/",
    headers={"Authorization": f"Bearer {token}"},
) as (read, write, _):
    async with ClientSession(read, write) as session:
        await session.initialize()

        # 3. 列出 Tools
        tools = await session.list_tools()
        print(tools)

        # 4. 调用 Tool
        result = await session.call_tool("list_datasets", {"pageSize": 5})
        print(result)

4.3 任意语言（curl 验证）

# 1. 登录
TOKEN=$(curl -s -X POST http://172.16.11.11:8079/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"agent-bot","password":"xxxxx"}' | jq -r '.data.token')

# 2. 列出 Tools（JSON-RPC initialize + list_tools）
curl -s -X POST http://172.16.11.11:8079/api/mcp/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"curl","version":"1.0"}}}'

curl -s -X POST http://172.16.11.11:8079/api/mcp/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}'

# 3. 调用 Tool
curl -s -X POST http://172.16.11.11:8079/api/mcp/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"list_datasets","arguments":{"pageSize":5}}}'

5. 权限说明

每个 Tool 对应一个或多个后端 API，权限由 url_permission 表控制：

Tool对应 API所需权限
list_datasetsGET /api/datasetsdataset:read
get_datasetGET /api/datasets/{id}dataset:read
create_jobPOST /api/jobsjob:create
list_jobsGET /api/datasets/{id}/jobsjob:read
get_jobGET /api/jobs/{id}job:read
list_tasksGET /api/jobs/{id}/taskstask:read
create_taskPOST /api/taskstask:create
trigger_aiPOST /api/agent/triggeragent:trigger
assign_taskPUT /api/tasks/{taskId}/assigntask:assign

Agent 用户的权限由管理员在平台后台分配，和普通用户一样管理。
